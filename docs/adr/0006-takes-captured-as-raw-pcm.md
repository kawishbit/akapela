# Takes are captured as raw PCM via AudioWorklet, not MediaRecorder

MediaRecorder is the obvious way to record a microphone in a browser, but it produces compressed WebM/Opus with timestamps that drift, which makes aligning the vocal to the Backing Track unreliable. Akapela uses an AudioWorklet to capture raw PCM sample-accurately, builds a WAV in the browser, and uploads that. Microphone constraints default to echo cancellation, noise suppression, and auto gain all off, because those processors mangle singing. Alignment against the Backing Track is the whole point of the app, so the extra code is justified.
