**What to build:** Nobody gets stuck on the first launch, and someone who wants Akapela on a server knows where to go. Next to the downloads, the steps an unsigned installer needs: on Windows, **More info → Run anyway** on "Windows protected your PC"; on macOS, **Done**, then **System Settings → Privacy & Security → Open Anyway**. Linux needs no step. When ticket 02 has picked a primary platform, that platform's step leads.

Below the downloads, a short "run it on a server" section: the three commands from the README, the warning that there is no login and anyone who can reach the port can use the library, and a link to the self-hosting docs on GitHub.

The README is the source of truth for this wording; say the same thing, not something new.
