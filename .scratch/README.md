# .scratch (archived)

This was Akapela's issue tracker until 2026-11-11: one directory per feature, holding a `spec.md` and one file per ticket under `issues/`. Every ticket here is closed.

Issues now live in GitHub Issues (see `docs/agents/issue-tracker.md`). This directory is kept as a read-only record of past specs and decisions. Don't add to it or change its statuses. Some `spec.md` headers and tables still show the status they had before their tickets closed; the `**Status:**` line in each ticket file is the final word.
